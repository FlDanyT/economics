# Economics

Приложение для планирования ежедневной выпечки. React, TypeScript, Tailwind CSS и Vite. Сервер и регистрация с паролем не требуются: данные хранятся в localStorage текущего браузера.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
cd Frontend
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`). Для проверки production-сборки выполните `npm run build`.

## Как попробовать

1. Откройте лендинг и нажмите «Открыть приложение» либо заполните форму регистрации без пароля.
2. Добавьте продукт в разделе «Продукты», укажите время приготовления, свежесть и срок продажи.
3. Запишите партию, затем продажи. Продажи можно записывать только в пределах доступного на тот момент количества.
4. После продаж за три разных завершённых дня обзор покажет оценку спроса. Для лучшего сравнения желательно иметь несколько записей за те же дни недели.
5. Укажите город и часы работы в настройках (смена в пределах одного дня). Погода загружается из Open-Meteo. Если запрос не выполнится, прогноз продолжит работать без погодной корректировки.

## Допущения модели

- Прогноз — среднее число продаж по сопоставимым дням. При наличии двух и более дней того же дня недели используются они; иначе дни такого же типа (праздник или обычный день), затем все дни истории.
- Используются основные фиксированные праздники России. Переносы выходных и региональные праздники не учитываются. При нехватке праздничных наблюдений условная корректировка составляет +10%.
- Погодные корректировки условны: осадки −5%, температура от 28 °C −3%. Эти коэффициенты не валидированы на реальных данных.
- Утренний план составляет 35–70% завтрашнего спроса в зависимости от периода свежести и часов работы; остаток можно приготовить позднее. Сегодняшняя рекомендация учитывает темп продаж после 20% рабочего дня, доступные остатки, время приготовления и закрытия.
- Продажи распределяются по партиям FIFO, если партия уже приготовлена и срок её продажи ещё не истёк. Списания уменьшают доступный остаток партии. Истёкшие партии не входят в запас для продажи.
- Чат, импорт Excel, кассовые интеграции и отправка формы контактов показаны как будущие возможности и не подключены.

Приложение не создаёт аккаунт и не отправляет введённые записи на сервер. Очистка данных браузера удалит записи.

Записи можно удалить через «Настройки» → «Очистить локальные данные».
